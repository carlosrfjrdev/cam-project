# Skill — cam-market-regime (DRAFT)

> Skill do **mundo financeiro do CaM** (CaM-only). Lead: **Ray**. Esqueleto / Stage 0.

## 1. Propósito

Classificar o **regime de mercado** vigente e suas implicações — read-only. Insumo de contexto para postura (Sun), risco (Nassim) e edge (Jim).

## 2. Quando acionar

- Leitura periódica de regime (ex.: início de pregão/semana).
- Sob demanda quando há suspeita de mudança de regime.

## 3. Lead + co-personas

- **Lead:** Ray (macro / regime).
- **Co:** Sun (consome o regime para decidir postura).

## 4. Procedimento (rascunho)

1. **Classificar** regime: tendência / lateralização / volatilidade alta / baixa.
2. **Mapear** ciclo macro relevante (juros, câmbio, fluxo, commodities).
3. **Implicações** de risco e oportunidade — em probabilidade, nunca previsão pontual.
4. **Entregar** leitura como contexto (não decisão).

## 5. Artefatos in/out

- **In:** dados de mercado, indicadores macro.
- **Out:** classificação de regime + implicações (read-only).
