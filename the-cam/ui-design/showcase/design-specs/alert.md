# Alert — DS CAM
**MUI:** `Alert` (era "MessageInfo").
## Severidades
info / success / warning / error — borda + texto na cor funcional; sempre com ícone/label (não só cor).
## CaM
- IA read-only (info, Art. 35º).
- Promoção de estratégia (success).
- Policy Engine da Carteira Hard: **warning = sugestão, nunca bloqueio** (R-13).
- DARF atrasada bloqueando operação (error, Art. 26º).
