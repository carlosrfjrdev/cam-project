# Switch — DS CAM
**MUI:** `Switch` (era "toggle").
## Estados
off, on (track `--primary`, thumb desliza), disabled (.4), focus (ring).
## A11y
`role=switch` + `aria-checked`; label clicável.
## CaM
Preferências (tema, alertas). **Flags constitucionais** (REAL_TRADING_ALLOWED, MULTI_STRATEGY_ENABLED, SCALING_ENABLED) aparecem `disabled` — ativação só via gate Founder, nunca toggle direto.
