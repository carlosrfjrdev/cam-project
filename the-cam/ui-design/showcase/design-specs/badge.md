# Badge — DS CAM
**MUI:** `Badge` (era "MessageChip").
## Variantes
contador (número), dot (status online/offline).
## Cores
default `--destructive` (atenção), primary `--primary` (neutro contável), dot ok/err.
## A11y
Texto alternativo do contador; status com `aria-label` (não só cor).
## CaM
Contador de alertas/decisões; status do heartbeat da bridge (ok/offline).
