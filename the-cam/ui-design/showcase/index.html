Design System CAM Esmeralda

Showcase navegável do Design System do CaM — The Carlos Alternative Money. Padronização visual do cockpit de gestão financeira: Full Web, Dark Mode First, Esmeralda como identidade, defesa de capital como princípio de UX. HTML vanilla + CSS. Logo provisório em texto puro: CaM.

Cada componente tem 3 artefatos: componente.html (visual), design-specs/componente.css (estilos) e design-specs/componente.md (spec legível por IA).
